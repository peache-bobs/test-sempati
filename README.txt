ГОТОВЫЙ САЙТ ДЛЯ GITHUB PAGES

1. Используйте отдельный репозиторий test-sempati (не подключённый к Lovable).
2. Распакуйте sempati-github-pages.zip.
3. Перетащите ВСЕ файлы из него в корень репозитория через Add file → Upload files. В этом архиве нет вложенных папок: структура больше не потеряется.
4. Commit changes.
5. Settings → Pages → Deploy from a branch → main → /(root) → Save.
6. Custom domain оставьте пустым. Дождитесь успешного pages build and deployment в Actions.
7. Адрес для репозитория test-sempati: https://peache-bobs.github.io/test-sempati/
Меню: https://peache-bobs.github.io/test-sempati/#/menu
QR: https://peache-bobs.github.io/test-sempati/#/qr

Это готовая статическая сборка. Lovable и его токены не нужны. Старые TS/TSX-файлы в корне test-sempati не используются этой сборкой. Не загружайте этот архив обратно в рабочий исходный проект Lovable.

ПРОВЕРКА
На опубликованной версии RU не реагировал; HTML ссылался на virtual:tanstack-start-dev-client-entry. Новая сборка использует скомпилированный JS и запускает React без серверной гидратации.
В браузере проверены смена EN/RU на настольной ширине и 375 px, открытие мобильной навигации, переход в меню, поиск kiymali, сочетание поиска с категорией, пустой результат, перезагрузка меню с сохранением языка, генерация QR. При 320 px меню не имеет горизонтального переполнения.
Это проверка мобильных размеров в браузере, не на физическом телефоне. Скачивание PNG не удалось подтвердить: инструмент ожидания загрузки завершился тайм-аутом. Физическая печать и сканирование камерой не проверены.
Демонстрационные цены, изображения и данные ресторана требуют согласования. Гарантия отсутствия всех возможных ошибок не заявляется.
